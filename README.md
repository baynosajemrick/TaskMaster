Features & Implementation Summary
Add Task: Users can input a task title using an intuitive HTML form, creating and storing new entries directly in the SQLite database.   
View Tasks: The main view fetches and displays a list of all existing tasks in real time using Blade templating.   Edit Task: Routes are configured to handle task property updates, allowing flexible task modifications.   
Delete Task: Includes a direct removal mechanism that deletes selected tasks from the database.   
Update Status: Features an interactive toggle button that switches a task's status between Pending and Completed with instant UI visual indicators (such as strike-through styling).
